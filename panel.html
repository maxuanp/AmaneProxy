来源 → 出口映射

      
每行一条 来源=出口，出口可填 jp/kr/us/direct/default（default = 默认出口）。未列出的来源走默认出口。

Amane 网络出口

      

      

        
        
        
        
      

      

        原理：把 Amane 的 network.proxy 指向 （本调度器的混合入口）。
        Amane 的刮削、图片代理、HLS、下载都会走这里，由调度器按域名分流。

        用 http 而不是 socks5：走 SOCKS5 时 httpx 会先把域名在本地解析成 IP 再交给代理，
        按域名分流就失效了（DNS 被污染时拿到的 IP 也没用）。HTTP CONNECT 会把域名原样带过来。
